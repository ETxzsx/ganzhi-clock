手机配网步骤
  1. 设备开启热点 GanZhi-Setup（开机未配网时自动开启）
  2. 手机连接该热点，自动弹出配置页面
  3. 选择家中 WiFi 并输入密码，等待连接成功
  4. 手机回到家中 WiFi，访问 ganzhi.local 或页面显示的 IP
内网热点（配网校时完成后）
  • 长按 BOOT 3 秒或点上方按钮：开启设备自带热点 GanZhi-Setup（开放网络，家中 WiFi 与校时不中断）
  • 手机连接该热点后访问 192.168.4.1，即可离线查看本页、起卦与同步界面
  • 再次长按 BOOT 或点按钮关闭热点
实体按键（板上六键：RST 复位 · BOOT · KEY0–KEY3）
  • BOOT 短按：切换 时钟 / 六爻 / 状态 / 星象 界面
  • BOOT 长按 3 秒：运行中开 / 关内网热点 · 配网中退出配网
  • KEY0 短按：起卦（自动跳到六爻界面）
  • KEY1 短按：版式循环（夜 / 昼 / 素·纯黑白）
  • KEY2 短按：亮度循环（4 档）
  • KEY3 短按：状态界面 · 长按 2 秒：休眠 / 唤醒
离线运行：设备以本地推算时间独立运行，联网仅用于校时——自动联网成功校时一次、手机接入热点校时一次、手机打开本页自动以手机时间校时一次（亦可点「校时到手机」随时重校），失败每 15 秒重试；校时成功后时间写入 Flash，断电重启自动恢复，无需持续联网。
